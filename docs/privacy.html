ChatPassport Privacy Policy

Effective September 9, 2026

ChatPassport helps users carry the visible text of an AI conversation between supported AI assistant websites. It operates locally in the user's browser and does not require a ChatPassport account or API key.

Data ChatPassport handles

After the user explicitly selects Preview current conversation, ChatPassport reads visible conversation text and basic metadata—message roles, source platform, page title, and page URL—from the active supported tab. A prepared transfer also handles that conversation and the user's new question. Imported ChatPassport JSON files are read locally only at the user's request.

This information may contain website content, personal communications, and user-generated content. ChatPassport does not read passwords, authentication cookies, payment information, or unrelated websites.

Use, storage, and retention

Data is used only to preview, export, or transfer a user-selected conversation and to place a combined continuation draft into a supported destination editor. ChatPassport never clicks Send automatically.

One pending transfer is stored in chrome.storage.session. It is removed when completed or cleared, expires after one hour, and is cleared when the browser session ends. Files are exported only through the browser's normal download flow.

Transmission and sharing

ChatPassport has no developer-operated backend and does not send conversation data, drafts, imported files, browsing history, or analytics to the developer, advertisers, analytics providers, or data brokers. Conversation data reaches an AI service only after the user reviews the draft and manually sends it on that service's website.

ChatPassport does not sell user data, use it for advertising or credit decisions, or allow the developer or other humans to read it.

Permissions

Access is limited to the official ChatGPT, Claude, Gemini, and DeepSeek domains. Chrome's scripting, storage, and side-panel permissions support user-initiated capture, one temporary transfer, destination-editor preparation, and the extension interface.

User controls

Users can clear a pending transfer in ChatPassport, delete exported files through their operating system, or uninstall the extension. Uninstalling removes extension-managed local data.

Chrome Web Store Limited Use

ChatPassport's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only for the disclosed conversation-transfer functionality.

Changes and contact

Material changes will update this page and its effective date. For privacy questions or support, open an issue on the ChatPassport issue tracker.
