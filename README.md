# ChatPassport

ChatPassport helps you move AI conversations between ChatGPT, Claude, Gemini,
and DeepSeek using a local-first, open conversation format.

## Goals

- Import and export conversations across supported AI assistants.
- Keep conversation data on your device.
- Use an open, portable format without tracking.

## Status

This project is in its early stages. The conversation format and usage
instructions will be added as the project develops.
